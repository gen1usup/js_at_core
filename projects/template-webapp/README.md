# Template Webapp Showcase

Small project template that demonstrates how a project can compose platform contracts, selectors, routes, repositories, gateway and queue-aware tests without browser runtime.

## What is included

- project adapter shape;
- route and selector definitions;
- auth provider example;
- template repository/gateway usage;
- Vitest scenario in `tests/template.test.ts`.

## Run

```bash
npm test
npx vitest run projects/template-webapp/tests/template.test.ts
```

This project is a showcase/template, not a generated application.
